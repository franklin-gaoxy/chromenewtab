# 启航 · 新标签页导航

**一个浏览器新标签页（Tab 页）插件**：把 Chrome / Edge 的默认新标签页换成你自己的导航页——常用网站按分组收纳、点开即达，同时自带搜索、时钟、AI 助手和浏览器书签侧边栏。

打开新标签页就能看到：居中的搜索框、图标网格、左侧分组栏、右侧书签抽屉。没有广告、不需要登录、数据只存在本机。

**它解决什么问题**

| 场景 | 用默认新标签页 | 用启航 |
| --- | --- | --- |
| 找常用网站 | 翻书签、敲网址 | 图标就在首页，点一下 |
| 网站太多 | 书签栏挤成一条 | 按分组收纳，滚轮上下切页、切分组 |
| 想搜点什么 | 先打开搜索引擎首页 | 顶部输入框直接搜，或筛选已存站点 |
| 想看时间 / 问 AI | 再开一个页面 | 首页放组件，点开即用 |
| 常用书签 | 拉下书签栏占地方 | 右侧抽屉按需展开，可拖宽度 |

- 技术栈：原生 HTML / CSS / JavaScript（Manifest V3），**无框架、无构建、无第三方依赖**
- 浏览器：Chrome / Edge 等 Chromium 内核浏览器（Chrome 100+）
- 安装方式：从 [Releases](https://github.com/franklin-gaoxy/chromenewtab/releases/latest) 下载 `qihang-nav-1.1.0.zip` → 解压 → 「加载已解压的扩展程序」（见[安装](#二安装三步)）

## 一、它能做什么

### 1. 分组 + 图标网格
- 左侧竖排分组栏，支持新建、重命名、清空、删除
- 图标可自由拖拽排序；拖到另一个分组图标上即可跨组移动
- **文件夹**：把一个图标拖到另一个图标的中间，两者合并成文件夹（像手机桌面）；再把别的图标拖到文件夹上即可放进去。文件夹只支持一层，点开是固定尺寸的深色面板，列数与主页每行图标数一致，面板内可搜索
- 每行图标数量（3~8）、整体对齐（居中 / 靠左 / 靠右）可调
- 内容超出时先滚动页面，到顶/到底后自动翻页，翻不动再切换分组（首尾循环）

### 2. 搜索
- 顶部搜索框：输入即筛选已保存的站点（支持跨分组）
- 按回车用当前搜索引擎搜索关键词，搜索引擎与分类（网页/图片/新闻/视频/地图）可切换
- `Ctrl / Cmd + K` 快速聚焦搜索框

### 3. 组件系统（可扩展）
右键 →「添加组件」，当前内置：

| 组件 | 占位 | 说明 |
| --- | --- | --- |
| 时钟 | 2 格 | 实时显示时间与日期 |
| AI 助手 | 1 格 | 点击打开对话弹窗，支持多模型、会话历史、提示词 |

新增组件只需按 `doc/ARCHITECTURE.md` 的「4.1 新增一个组件」注册，其余 UI 自动生效。

### 4. AI 助手
仿对话产品的界面：左侧是会话历史，底部是输入框，右上角齿轮进入设置。

- **模型**：任意兼容 OpenAI Chat Completions 的接口，可增删改查（名称 / 接口地址 / 模型名 / API Key）
- **会话**：自动保存历史，可新建、切换、删除
- **提示词**：常用提示词库，一键插入输入框
- **联网 / 深度思考**：作为请求参数附加，是否生效取决于你的接口
- 默认预置 DeepSeek（`https://api.deepseek.com/v1` / `deepseek-chat`），填入自己的 API Key 即可使用

### 5. 浏览器书签
- 屏幕右侧悬浮书签按钮，点击展开侧边栏（按钮位置可选靠上 / 居中 / 靠下）
- 按层级展示浏览器书签，文件夹可展开/折叠
- 顶部搜索框支持**模糊查找**（先连续包含，再按字符顺序匹配）
- 拖动侧边栏左边缘可调整宽度

### 6. 书签双向同步
右键 →「同步书签」，在同一侧边栏内完成：

| 方向 | 行为 |
| --- | --- |
| 主页 → 书签 | 在指定书签目录下，为每个分组创建同名文件夹，把网站写进去；主页里的文件夹会建成同名子文件夹（只一层），按网址去重 |
| 书签 → 主页 | 把指定目录的书签导入指定分组，两种模式见下 |

从书签导入的两种模式：

1. **保留一级目录**（默认）：所选目录下直接包含的书签放进分组；每个一级子目录在主页生成同名文件夹，其中的书签（含更深层级）全部收进这个文件夹
2. **仅当前目录**：只同步该目录下直接包含的书签，子目录忽略

导入时会过滤非 http(s) 地址，并按网址与分组内已有站点去重。

### 7. 外观与数据
- 内置多套背景（雾林、矢量雾林等），也可粘贴图片链接或上传本地图片
- 可关闭图标下方名称
- **备份与恢复**：导出 / 导入 JSON（含分组、站点、设置）
- **导出浏览器书签**：生成 Netscape 书签 HTML，可导入 Chrome 书签管理器
- **远程同步（可选）**：自建 QSP v1 服务端后可在多台设备间上传、下载、合并，协议见 `doc/PROTOCOL.md`，仓库内 `server/` 提供零依赖示例服务端

## 二、安装（三步）

发布包只通过 **Release 资产**分发（源码仓库内不含 zip，打包由发布流程生成）：

- **下载地址**：[Releases · v1.1.0](https://github.com/franklin-gaoxy/chromenewtab/releases/tag/v1.1.0) → 点 `qihang-nav-1.1.0.zip`

1. **下载** `qihang-nav-1.1.0.zip`
2. **解压**到任意**固定位置**，例如 `D:\Extensions\qihang-nav`
   - 解压后的根目录里应能直接看到 `manifest.json` 和 `src/` 文件夹
   - 请保留该文件夹，浏览器加载的是解压后的目录，而不是 zip 本身
3. **加载**：打开 `chrome://extensions`（Edge 为 `edge://extensions`）
   - 打开右上角「开发者模式」
   - 点击「加载已解压的扩展程序」，选择**解压后的根目录**（含 `manifest.json` 的那一层）

安装完成后打开新标签页即可使用，无需额外配置。

> 如果新标签页仍是浏览器默认页或其他扩展的页面，请在扩展列表里禁用其他会接管新标签页的扩展。

### 从源码加载（开发时）

本项目没有构建步骤，加载源码目录即可：

- Chrome 中选择「加载已解压的扩展程序」→ 指向仓库根目录（`manifest.json` 所在目录）
- 修改 `src/` 下的文件后，在扩展管理页点击「重新加载」并刷新新标签页
- 修改 `manifest.json`（如权限）后必须重新加载扩展

## 三、操作流程（快速上手）

### 第一次使用

1. **添加网站**：在新标签页空白处右键 →「添加网站」，填写名称与网址（可只填 `juejin.cn`），图标留空会自动获取
2. **新建分组**：右键 →「新建分组」，或点左侧分组栏底部的「+」
3. **整理图标**：按住图标拖动排序；把图标拖到左侧分组图标上即可移动到该分组
4. **调整布局**：右键 →「设置」→「布局」，设置每行图标数量、对齐方式、书签按钮位置
5. **更换背景**：右键 →「更换背景」，选择预设或粘贴图片链接

### 日常使用

| 想做的事 | 操作 |
| --- | --- |
| 搜索网址 | 直接在顶部输入，回车用搜索引擎搜索 |
| 在已保存站点中查找 | 输入关键词，网格会实时筛选（跨分组） |
| 打开站点菜单 | 右键图标：打开 / 复制链接 / 编辑 / 删除 |
| 上下浏览 | 鼠标滚轮：先滚动页面 → 到边界翻页 → 再切换分组（循环） |
| 新建分组 | 左侧分组栏底部「+」 |
| 重命名分组 | 右键分组图标 →「重命名」 |
| 跨组移动站点 | 把图标拖到目标分组图标上 |
| 新建文件夹 | 把一个图标拖到另一个图标的中间（左右边缘仍是插入排序） |
| 往文件夹里加图标 | 把图标拖到文件夹图标上 |
| 打开文件夹 | 点击文件夹图标（固定尺寸面板，列数跟随「每行图标数」） |
| 整理文件夹 | 右键文件夹：重命名 / 解散 / 删除；面板内右键站点可编辑、移出、删除 |
| 添加组件 | 右键空白处 →「添加组件」 |
| 打开书签侧边栏 | 点屏幕右侧的悬浮书签图标（位置可在设置中调整） |
| 收起书签侧边栏 | 点面板以外的任意位置，或 X、`Esc`、再点一次悬浮按钮 |
| 调整书签栏宽度 | 拖动侧边栏的左边缘 |
| 搜索书签 | 侧边栏顶部输入框，支持模糊匹配 |
| 书签与主页互转 | 右键空白处 →「同步书签」 |

### 配置 AI 助手

1. 右键 →「添加组件」→「AI 助手」，网格中出现 AI 图标
2. 点击 AI 图标打开对话弹窗
3. 点右上角**齿轮** →「模型设置」→「新增模型」，或编辑预置的 DeepSeek：
   - 接口地址：`https://api.deepseek.com/v1`（也支持带 `/chat/completions` 的完整地址）
   - 模型名：如 `deepseek-chat`
   - API Key：你的密钥（只保存在本机浏览器存储中）
4. 点「保存」→「设为当前」→「返回对话」
5. 在底部输入框提问，`Enter` 发送、`Shift + Enter` 换行
6. 可选：点「联网」「深度思考」开关；在设置 →「提示词」里维护常用提示词

> 第一次发送时浏览器会询问是否允许访问该接口域名（可选权限），允许后才能请求。

### 同步浏览器书签

**主页 → 书签**

1. 右键空白处 →「同步书签」
2. 顶部选择「主页 → 书签」
3. 在「目标书签目录」中选择要写入的位置（例如「书签栏」）
4. 点「同步到书签」：每个分组生成同名文件夹，主页里的文件夹生成同名子文件夹，已存在的同名网址会跳过

**书签 → 主页**

1. 切换到「书签 → 主页」
2. 选择「源书签目录」与「目标分组」
3. 选择模式：**保留一级目录**（子目录在主页变成文件夹，其中的书签全部收进去）或 **仅当前目录**（忽略子目录）
4. 点「同步到分组」

### 备份与迁移

- 导出：右键 →「设置」→「备份与恢复」→「导出备份」，得到 JSON
- 导入：同一页面 →「导入备份」，选择 JSON（会覆盖当前数据）
- 文件夹结构会随备份一起导出 / 导入，导出浏览器书签时同样保留一层目录
- 迁移到别的电脑：先导出 JSON，在新机器安装后导入

## 四、权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存分组、站点、设置与会话数据（本机） |
| `favicon` | 读取站点图标用于图标网格 |
| `bookmarks` | 书签侧边栏展示与「书签 ↔ 主页」同步 |
| `optional_host_permissions` | AI 请求外部接口时临时申请该域名权限 |

扩展不收集任何数据：导航数据只存在本机；AI 请求直接发往你自己配置的接口；远程同步只发送到你自己的服务器。

## 七、常见问题

**Q：书签侧边栏提示「仅在扩展环境中可用」？**
说明页面是以 `file://` 方式打开的，或扩展没有加载成功。请通过浏览器扩展方式安装后再打开新标签页。

**Q：AI 提示「未授权访问该接口地址」？**
首次请求需要允许该域名权限，请在弹出的浏览器提示中选择允许；若已拒绝，可到扩展详情页的「网站访问权限」中重新开启。

**Q：图标显示成首字母方块？**
该站点没有可用的 favicon，或图标地址失效。可右键 →「编辑」→ 手动填写图标地址或上传图片。

**Q：修改代码后没有生效？**
在扩展管理页点击「重新加载」，然后刷新新标签页；修改 `manifest.json` 后必须重新加载。

**Q：数据会丢吗？**
数据保存在浏览器本机存储中。清理浏览器数据、卸载扩展会丢失，建议定期用「导出备份」保存 JSON。
