定时备份

每天执行时间

保存位置

默认位置：浏览器下载目录 → qihang-backup 文件夹

下载目录就是 Chrome 保存下载文件的那个文件夹，Windows 上通常是 C:\Users\你的用户名\Downloads，可在 chrome://settings/downloads 查看或修改。想放到 C 盘其他位置，点「自定义目录」选过去即可。

保留天数

0 表示永久保留。两种位置都会按天数自动清理过期备份：默认位置清理「下载目录/qihang-backup」下的文件（需保留对应的下载记录），自定义目录直接删除文件。

浏览器书签（HTML）

生成标准 Netscape 书签文件，所有站点收纳在「启航导航」文件夹内。在 Chrome 书签管理器右上角 ⋮ → 导入书签，选择该文件即可，书签栏只会多出一个目录。
